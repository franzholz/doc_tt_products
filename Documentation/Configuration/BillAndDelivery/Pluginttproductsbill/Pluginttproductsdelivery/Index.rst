
.. _configuration-billdelivery-generation:

..  confval:: configuration-billdelivery-generation
    :name: generation of a bill or delivery sheet
    :required: true
    :type: string

    Defines the behaviour for the generation of the bill/delivery sheet.
        * auto: Generation will be done when the order is finalized.

    **Example:**

    ..  code-block:: typoscript
    :caption: automatic generation of a bill

    plugin.tt_products.bill {
        generation = auto
    }

    **Example:**

    ..  code-block:: typoscript
    :caption: no generation of a delivery sheet

    plugin.tt_products.delivery {
        generation =
    }

.. _configuration-billdelivery-type:

..  confval:: configuration-billdelivery-type
    :name: Type of bill or delivery
    :required: true
    :type: string

    Defines the behaviour for the generation of the bill/delivery sheet.
        *    html:  HTML format
        *    pdf:   PDF format (extension 'fpdf' must have been installed.)


.. _configuration-billdelivery-handlelib:

..  confval:: configuration-billdelivery-handlelib
    :name: PHP library for PDF generation - **only for PDF**
    :required: false
    :type: string / array

    Name of the PHP library to handle the PDF generation.
    Currently you can set only 'PhpWord' here.

    **Example:**

    ..  code-block:: typoscript
    :caption: no generation of a delivery sheet

    bill.handleLib = PhpWord

    **array values**:
        *    path: file path to the library, relative to the TYPO3 directory
        *    rendererLibrary.path: file path to the helper
        *    library to generate formats which the main library cannot handle


    **Example:**

    ..  code-block:: typoscript
    :caption: generation of a PDF bill generated by PHP Word

    bill.handleLib = PhpWord 
    bill.handleLib { 
        path = PHPWord-master
        rendererLibrary {
             path = dompdf-0.6.1
        } 
    }
