
.. _configuration-error:

Error configuration
-------------------

Setup only.

You can set the behaviour of tt_products in case of errors. The file pi1/locallang.xml contains the
list of tags for the error messages.


.. _configuration-error-wrong-parameter-redirect:

..  confval:: redirect
    :name: redirect page id
    :required: false
    :type: array

    *   pid: page id for redirection page.
