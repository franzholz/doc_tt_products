MEMO-Vormerk Seite
------------------

Ein eingeloggter Benutzer kann, ebenso wie ein nicht eingeloggter, Produkte zu einer Vormerk-Seite
hinzufügen. Diese Memo Seite wird in der :php:`fe_users` Tabelle oder in der Frontend 
Sitzung gespeichert. Erzeugen Sie einfach einen neue Seite mit dem Shop Plugin als 
Inhalt und geben Sie den Anzeige-Modus "Memo Items"ein. Sie müssen
auch den Anfangspunkt setzen, wie auf den :php:`SEARCH` Seiten.
