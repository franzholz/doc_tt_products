
.. _configuration-error:

Error configuration
-------------------

Setup only.

You can set the behaviour of tt_products in case of errors. The :file:`Resources/Private/Language/Pi1/locallang.xlf` contains the
list of tags for the error messages.

redirect
~~~~~~~~

..  confval:: redirect
    :name: redirect page id
    :required: false
    :type: array

    *   pid: page id for redirection page.
